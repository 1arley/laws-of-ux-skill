# Laws of UX

A portable Agent Skill for auditing existing web pages and planning new ones with practical, evidence-aware UX guidance.

## Install

```sh
npx skills add 1arley/laws-of-ux-skill --skill laws-of-ux
```

The skill routes between existing-page audits and new-page planning. It uses [Laws of UX](https://lawsofux.com/) as a set of design lenses and points to [WCAG 2.2](https://www.w3.org/TR/WCAG22/) for testable web accessibility requirements.
